# Антискам-бот для Telegram

Учебный проект Анастасии Подковыриной. Бот ищет признаки мошенничества в русскоязычных сообщениях и объясняет, какие правила сработали.

Отправьте боту текст напрямую или воспользуйтесь командой `/scanmessage`. В ответ бот покажет уровень риска, балл по шкале от 0 до 100 и до трёх причин срабатывания.

## Возможности

- `/start` — знакомство с ботом.
- `/help` — подсказка по использованию.
- `/scanmessage` — приглашение отправить текст на проверку.
- Текстовые сообщения — проверка по шаблонам и регулярным выражениям.

Балл отражает совпадения с правилами. Подозрительное сообщение может получить низкий балл, а обычное — вызвать предупреждение. Ссылки анализируются как часть текста. Проверка сайтов и вложений пока отсутствует.

## Как устроен анализ

1. Бот приводит текст к нижнему регистру, заменяет «ё» на «е» и убирает лишние пробелы и знаки пунктуации.
2. RapidFuzz сравнивает подготовленный текст с шаблонами. Совпадения ключевых слов влияют на оценку шаблона.
3. Регулярные выражения ищут в исходном тексте отдельные признаки, например сокращённые ссылки и слова срочности.
4. Анализатор объединяет сигналы в балл. Порог среднего риска — 30, высокого — 60.

## Локальный запуск

Понадобятся Python 3.9 или новее и токен Telegram-бота от BotFather.

1. Клонируйте репозиторий и установите зависимости в виртуальное окружение.

   ```bash
   git clone https://github.com/Nastya-P-E/formyproject.git
   cd formyproject
   python3 -m venv .venv
   source .venv/bin/activate
   python -m pip install -r requirements.txt
   ```

   В PowerShell используйте `py -m venv .venv` и `.\.venv\Scripts\Activate.ps1` для создания и активации окружения.

2. Создайте `.env` в корне репозитория из файла [.env.example](.env.example) и подставьте токен в `BOT_TOKEN`. Храните рабочий токен только в локальном `.env`.

3. Запустите бот из корня репозитория.

   ```bash
   python "бот/main.py"
   ```
