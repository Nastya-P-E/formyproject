# Антискам-бот для Telegram

Учебный проект Анастасии Подковыровой. Бот ищет признаки мошенничества в русскоязычных сообщениях и объясняет, какие правила сработали.

Отправьте боту текст напрямую или воспользуйтесь командой `/scanmessage`. В ответ бот покажет уровень риска, балл по шкале от 0 до 100 и до трёх причин срабатывания.

## Возможности

- `/start` — знакомство с ботом.
- `/help` — подсказка по использованию.
- `/scanmessage` — приглашение отправить текст на проверку.
- `/scanlink` — проверка адреса ссылки.
- `/scanfile` — проверка файла на вредоносное ПО.
- `/stop` — отмена текущего режима.
- Текстовые сообщения — проверка по шаблонам и регулярным выражениям.
- До трёх ссылок из текста — дополнительная проверка адресов.

Балл отражает совпадения с правилами. Подозрительное сообщение может получить низкий балл, а обычное — вызвать предупреждение. Ссылки проверяются по признакам в адресе; бот не открывает сайты и не проверяет содержимое файлов. По умолчанию внешние сервисы отключены.

## Как устроен анализ

1. Бот приводит текст к нижнему регистру, заменяет «ё» на «е» и убирает лишние пробелы и знаки пунктуации.
2. RapidFuzz сравнивает подготовленный текст с шаблонами. Совпадения ключевых слов влияют на оценку шаблона.
3. Регулярные выражения ищут в исходном тексте отдельные признаки, например сокращённые ссылки и слова срочности.
4. Анализатор объединяет сигналы в балл. Порог среднего риска — 30, высокого — 60.

## Локальный запуск

Понадобятся Python 3.10 или новее (рекомендуется 3.11+) и токен Telegram-бота от BotFather.

1. Клонируйте репозиторий и установите зависимости в виртуальное окружение.

   ```bash
   git clone https://github.com/Nastya-P-E/formyproject.git
   cd formyproject
   python3 -m venv .venv
   source .venv/bin/activate
   python -m pip install -r requirements.txt
   ```

   В PowerShell используйте `py -m venv .venv` и `.\.venv\Scripts\Activate.ps1` для создания и активации окружения.

2. Создайте `.env` в корне репозитория из файла [.env.example](.env.example) и подставьте токен в `BOT_TOKEN`. Храните рабочий токен только в локальном `.env`.

3. Запустите бот из корня репозитория.

   ```bash
   python "бот/main.py"
   ```

## Необязательная интеграция VirusTotal

Для запуска бота достаточно `BOT_TOKEN`. Внешняя проверка по умолчанию отключена.
Если она нужна, задайте в локальном `.env` `VIRUSTOTAL_ENABLED=true` и `VIRUSTOTAL_API_KEY`.
При включении адрес ссылки передаётся VirusTotal для чтения существующего отчёта.
Новые сканирования бот не создаёт. Отчёт может отсутствовать или устареть; статус виден в ответе.
Не присылайте приватные ссылки, адреса с паролями и одноразовыми кодами.
Локальные IP-адреса не отправляются во внешний сервис.

## Проверка перед запуском

```bash
python -m unittest discover -s tests -v
```

Тесты не используют действующий токен и не обращаются к Telegram или VirusTotal.
Проверяются команды, переходы между режимами, ошибочные URL, HTML-экранирование,
локальные признаки ссылок и статусы подменённых ответов VirusTotal.

Если токен когда-либо попадал в GitHub, отзовите его через BotFather и получите новый.
Удаление `.env` из репозитория не отзывает секрет и не убирает его из старых коммитов.
Новый токен внесите только в локальный `.env`, не в `.env.example`.
