# Антискам-бот для Telegram

Учебный проект Анастасии Подковыровой. Бот ищет признаки мошенничества в русскоязычных сообщениях и адресах ссылок и объясняет, какие правила сработали.

Отправьте текст напрямую или используйте `/scanmessage`. В ответ бот покажет уровень риска, внутренний балл от 0 до 100 и до трёх причин срабатывания. Число не является вероятностью мошенничества: опасное сообщение может получить низкий балл, а обычное — вызвать предупреждение.

## Что работает

| Команда или сообщение | Результат |
| --- | --- |
| `/start` | Знакомство с ботом, сброс текущего режима |
| `/help` | Справка и ограничения проверки |
| `/scanmessage` → текст | Проверка сообщения по шаблонам и регулярным выражениям |
| `/scanlink` → одна ссылка | Проверка признаков в адресе ссылки |
| `/scanfile` → документ | Проверка имени, SHA-256 и при настройке — готовых записей во внешних базах |
| `/stop` | Отмена ожидания текста, ссылки или документа |
| Текст без команды | Анализ текста и дополнительно до трёх найденных ссылок с `http://`, `https://` или `www.` |
| Документ без команды | Та же проверка файла, лимит 10 МиБ |
| Фото, голосовое или другое неподдерживаемое вложение | Подсказка прислать текст, ссылку или документ |

Максимальная длина входного текста — 4000 символов. Бот не открывает проверяемые сайты и не исследует содержимое страниц. По умолчанию проверка ссылок выполняется локально; внешний сервис VirusTotal включается отдельно.

**Проверка документов подключена.** Без дополнительных ключей доступны только признаки имени/расширения и SHA-256. Это не полноценный антивирус: отсутствие подозрительного расширения не доказывает безопасность содержимого.

## Как устроена проверка

### Текст

1. Текст приводится к нижнему регистру, «ё» заменяется на «е», удаляются знаки пунктуации и лишние пробелы.
2. RapidFuzz сравнивает подготовленный текст с 17 шаблонами мошеннических сообщений. Совпадения ключевых слов влияют на балл.
3. Регулярные выражения ищут отдельные признаки: сокращённые ссылки, реквизиты и слова срочности.
4. Сигналы объединяются в оценку: ниже 30 — низкий риск, от 30 до 60 — средний, от 60 — высокий.

Алгоритм опирается на заранее заданные правила. Он может ошибаться на перефразированных просьбах, предупреждениях, цитатах и обычных срочных сообщениях. Отсутствие найденных признаков не подтверждает безопасность. Отдельные классы «спам» и «фишинг» бот не выдаёт.

### Ссылки

Проверяются формат адреса, сокращатели, IP-адрес вместо домена, доменные зоны, punycode, слова в URL и возможные упоминания брендов в чужом домене. Это косвенные признаки: например, слово `login` или международный домен сами по себе не доказывают фишинг.

При включении VirusTotal бот запрашивает существующий отчёт об адресе. Новые сканирования не создаются. В ответе показано, получен ли отчёт, отсутствует ли он или сервис недоступен. Старый отчёт может быть неактуальным.

### Документы

`/scanfile` включает ожидание документа; также можно отправить документ сразу. Лимит бота — **10 МиБ**, он проверяется по метаданным и фактически скачанным байтам. Это собственное ограничение ниже [лимита скачивания Telegram Bot API](https://core.telegram.org/bots/api#file).

Файл скачивается из Telegram во временное хранилище, не запускается и удаляется после обработки. Вычисляются SHA-256 и признаки исполняемого или двойного расширения. Результат включает полный хэш, найденные признаки и отдельные статусы VirusTotal и MalwareBazaar.

По умолчанию обе внешние базы отключены. Без готового отчёта и без найденных признаков бот пишет «Безопасность не определена», не выдавая балл безопасности. Ошибка скачивания и превышение размера также не получают зелёного `0/100`. Ошибка сервиса, отсутствующий хэш и успешный отчёт показываются раздельно. Даже готовый отчёт без обнаружений не гарантирует безопасность файла.

Если внешние проверки включены, сервисам передаётся только SHA-256. Содержимое документа им не загружается. HTTP и анализ скачанного файла выполняются в рабочем потоке, не блокируя обработку команд. Одновременно обрабатываются до двух документов. `/stop` отменяет ожидание нового ввода; уже начатая проверка документа завершается отдельно.

## Локальный запуск

Понадобятся Python 3.10 или новее (рекомендуется 3.11+) и действующий токен Telegram-бота от BotFather.

1. Установите зависимости в виртуальное окружение:

   ```bash
   git clone https://github.com/Nastya-P-E/formyproject.git
   cd formyproject
   python3 -m venv .venv
   source .venv/bin/activate
   python -m pip install -r requirements.txt
   ```

   В PowerShell создайте окружение командой `py -m venv .venv` и активируйте его через `.\.venv\Scripts\Activate.ps1`.

2. Создайте в корне репозитория обычный текстовый файл `.env` по образцу [.env.example](.env.example). Подставьте токен в `BOT_TOKEN`:

   ```dotenv
   BOT_TOKEN=your_bot_token_here
   VIRUSTOTAL_ENABLED=false
   VIRUSTOTAL_API_KEY=
   ```

   Файл должен называться именно `.env`, без расширений `.txt` и `.rtf`. Не загружайте его в GitHub и не вставляйте токен в исходники. Если токен уже публиковался, отзовите его через BotFather: удаление из текущих файлов не удаляет старые коммиты и не отзывает токен.

3. Выполните локальные проверки:

   ```bash
   python -m unittest discover -s tests -v
   ```

4. Запустите бота из корня репозитория:

   ```bash
   python "бот/main.py"
   ```

   При успешном соединении появятся записи `Bot started` и `Run polling`. Остановка — `Ctrl+C`. Для одного токена должна работать одна копия, получающая сообщения через polling. Одновременный запуск на компьютере и сервере вызывает конфликт.

### Необязательная интеграция VirusTotal для ссылок

Для работы с текстом и адресами достаточно `BOT_TOKEN`. Чтобы включить поиск отчётов VirusTotal для ссылок, задайте в локальном `.env`:

```dotenv
VIRUSTOTAL_ENABLED=true
VIRUSTOTAL_API_KEY=your_virustotal_api_key_here
```

При включении адрес ссылки передаётся VirusTotal. Не отправляйте приватные ссылки, адреса с паролями и одноразовыми кодами. Локальные IP-адреса не передаются внешнему сервису. Без ключа или при ошибке сервиса остаётся только локальная проверка признаков.

Этот же переключатель VirusTotal включает поиск готовых отчётов по SHA-256 документов. Для MalwareBazaar отдельно задайте:

```dotenv
MALWAREBAZAAR_ENABLED=true
MALWAREBAZAAR_API_KEY=your_abusech_auth_key_here
```

Для запросов нужен [Auth-Key от abuse.ch](https://bazaar.abuse.ch/api/#auth_key). Если ключей нет, оставьте оба сервиса выключенными. Бот не утверждает, что выполнил антивирусную проверку без доступа к базам.

## Проверки и ограничения

В `tests/test_bot.py` и `tests/test_files.py` — 16 автоматических тестов. Они проверяют команды и состояния, обработку документов, неподдерживаемые вложения, неверные URL, HTML-экранирование, статусы сервисов, SHA-256, фактический лимит скачивания, очистку временных файлов и неблокирующее выполнение.

Тесты не используют действующие ключи и не обращаются к Telegram, VirusTotal или MalwareBazaar. Ответы внешних сервисов подменяются. Успешные тесты не доказывают качество распознавания мошенничества. Для оценки качества нужен отдельный размеченный набор обычных и мошеннических сообщений, разбор ложных тревог и пропусков.
